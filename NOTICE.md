# Notice

Blockiverse VR is an original voxel sandbox project.

The project may be visually inspired by broad voxel sandbox conventions, but it must not copy Minecraft's protected identity. Do not commit or use Minecraft names, logos, screenshots, textures, UI, music, sounds, mob names, character names, fonts, item names used as distinctive branding, or characters visually derived from protected Minecraft characters.

All original project assets, including generated art and audio, must include provenance notes in `docs/art-direction/prompt-log.md` or a nearby source file when practical.

## Third-party audio

Blockiverse VR's music is original and generated by `scripts/audio/generate-audio.py`. Its sound effects are built from licensed third-party source recordings, processed into original cues by `scripts/audio/build-audio-assets.py`.

Every committed sound effect is traceable to its source in
[`docs/audio/audio-asset-manifest.md`](docs/audio/audio-asset-manifest.md), which records the cue, the output file, the source pack, the source file, and the license. Raw source bundles are staged outside the repository and are never committed.

The following sources are used. All permit commercial use, modification, and distribution inside a commercial game. None require attribution; this notice is kept for provenance, not because a license compels it.
